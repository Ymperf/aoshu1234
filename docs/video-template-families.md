# Teacher Video Template Families

## 1. `travel_blackboard_v2`
- 适用 topic:
  行程基础、行程综合、行程综合难题、工程问题、发车间隔、追及、相遇、流水
- Scene grammar:
  `hook -> model -> formula -> problem -> worked_example -> variant -> summary`
- 画面语法:
  路线图、方向箭头、速度关系图、不变量高亮、连续板书
